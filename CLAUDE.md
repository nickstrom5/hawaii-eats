## Data rules
- No Google-derived data in the app: `HI_APP=1` writes `data/app/places.json`; copy it to `HawaiiEats/Resources/` after every rebuild.
- **No current official list** (playbook/12-sources.md): DOH placards (HAR 11-50) are looked up one at a time on DOH's site, whose
  search keeps robots out (never harvest it; the app links health.hawaii.gov/san/). County liquor lists: Maui's PDF is bot-checked (Nick
  downloads by hand into data/raw/official/maui/ if wanted; its parser isn't written yet), Honolulu's site disallows ClaudeBot,
  Kauaʻi's robots.txt disallows its licensee inquiry, Hawaiʻi County answers 403. A UIPA request for a bulk extract needs Nick's yes.
- DOH's 2011 statewide and 2013 Oʻahu permit lists: history hints and calibration only, never proof a place is open; never show Permit
  Holder, Owner or Telephone.
- Geography: State GIS coastlines (islands), 2020 Census places (towns, Lahaina CDP) and county lines (`pipeline/fetch_geo.py`); USGS GNIS
  for official spellings (`common.canon_city`). Matching folds the ʻokina, apostrophes and kahakō; display keeps the official form.
  Kailua (Oʻahu) vs Kailua-Kona and Waimea by island; mailing towns on the wrong island take their Census place.
- Hawaiian zone house numbers ("75-5770 Aliʻi Dr", "94-50" = "94-050") are one number (`official.HNUM`).
- Lahaina: listings inside the Lahaina CDP are dropped unless hand-checked with a 2025-26 source; Kāʻanapali, Nāpili-Honokōwai and
  Kapalua (same 96761 mailing address) show under their own names. Military-base food courts are dropped.
- Adult clubs: `data/research/adult_venues.json` (Overture's adult category); an address counts only with the club's name, because the
  clubs share plaza addresses with real restaurants. Hotel restaurants ("Bali by the Sea at Hilton Hawaiian Village") stay visible.
- Guides list only hand-checked places (`hc`), from the research in `data/research/app/*.json` and `jbf.json` (first pass 2026-10-20,
  65 places; leads in `data/research/app/LEADS.md`). Musubi and Loco Moco are separate guides (Nick, 2026-10-20; tag bit 1024 musubi).
- Website links: `pipeline/check_websites.py` (2026-10-21: 3,011 checked, 1,735 ok, 51 hijacked to gambling or adult pages). Order:
  export, check, export. `pipeline/website_blocklist.json` (SinglePlatform directory pages) is applied by hawaii.py and make-site.py.

## Rebuild
```bash
.venv/bin/python pipeline/fetch_overture.py && .venv/bin/python pipeline/fetch_geo.py
cd pipeline && ../.venv/bin/python listings.py && ../.venv/bin/python geocode_official.py && ../.venv/bin/python calibrate.py \
  && ../.venv/bin/python hawaii.py && HI_APP=1 ../.venv/bin/python hawaii.py && cd ..
cd pipeline && ../.venv/bin/python check_websites.py && HI_APP=1 ../.venv/bin/python hawaii.py && cd ..
cp data/app/places.json HawaiiEats/Resources/ && .venv/bin/python scripts/make-leaderboard.py && .venv/bin/python scripts/make-site.py \
  && QA_PORTS=8884-8890 .venv/bin/python scripts/qa-site.py
```

## Build the app
- `xcodegen generate` (never commit the .xcodeproj). Compile: `xcodebuild build-for-testing -project HawaiiEats.xcodeproj -scheme HawaiiEats -destination 'generic/platform=iOS Simulator' -derivedDataPath ./DerivedData CODE_SIGNING_ALLOWED=NO`
- Our simulators (UDIDs in `.simulators`): "HI Eats 6.9" (iPhone 17 Pro Max) and "HI Eats iPad 13", iOS 27.0. One booted at a time; check
  `ps -u $(id -u) | wc -l` and that fewer than two other "… Eats" simulators are booted first; shut down when done.
- Unit tests `-only-testing:HawaiiEatsTests` with `CODE_SIGNING_ALLOWED=NO`. UI smoke test `-only-testing:HawaiiEatsUITests` without
  it (rewritten for Hawaii 2026-10-21; not run yet).
- App Store builds use the public Xcode: `DEVELOPER_DIR="/Applications/Xcode 1.app/Contents/Developer"`.
